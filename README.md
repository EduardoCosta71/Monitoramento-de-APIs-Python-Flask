# Monitoramento de APIs

Sistema web desenvolvido com Python e Flask para monitorar APIs e URLs, verificando seu status HTTP e tempo de resposta.

## Funcionalidades

- Monitoramento de múltiplas APIs
- Verificação de status HTTP
- Medição do tempo de resposta
- Identificação de APIs ONLINE
- Tratamento de erros e timeout
- Interface web com Flask
- Dashboard desenvolvido com HTML e CSS

## Tecnologias

- Python
- Flask
- Requests
- HTML
- CSS
