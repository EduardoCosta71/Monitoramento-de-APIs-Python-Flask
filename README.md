# Monitoramento de APIs — Python + Flask

Aplicação web desenvolvida com Python e Flask para monitorar APIs, verificar seus status de resposta e visualizar os resultados em uma interface web.

O projeto foi criado para praticar desenvolvimento Backend, consumo de APIs HTTP, tratamento de respostas e integração entre Python e uma interface web.

## Tecnologias utilizadas

* **Python** — linguagem principal do projeto.
* **Flask** — criação da aplicação web e gerenciamento de rotas.
* **Requests** — realização de requisições HTTP para as APIs monitoradas.
* **HTML5** — estrutura das páginas.
* **CSS3** — estilização da interface.
* **Git e GitHub** — versionamento e gerenciamento do código.

## Funcionalidades

* Monitoramento de APIs por meio de requisições HTTP.
* Verificação de status e identificação de erros nas respostas.
* Classificação dos resultados de monitoramento.
* Exibição das informações em uma interface web.
* Cadastro de APIs para monitoramento, conforme implementado no projeto.

## Como executar o projeto

### 1. Pré-requisitos

Antes de começar, instale:

* Python 3
* Git

### 2. Clone o repositório

```bash
git clone https://github.com/EduardoCosta71/Monitoramento-de-APIs-Python-Flask.git
```

### 3. Acesse a pasta do projeto

```bash
cd Monitoramento-de-APIs-Python-Flask
```

### 4. Crie um ambiente virtual

```bash
python -m venv venv
```

Ative o ambiente virtual no Windows:

```bash
venv\Scripts\activate
```

### 5. Instale as dependências

Se o projeto possuir um arquivo `requirements.txt`, execute:

```bash
pip install -r requirements.txt
```

Caso ainda não possua esse arquivo, instale as dependências utilizadas pelo projeto e gere o arquivo posteriormente.

### 6. Execute a aplicação

Utilize o comando correspondente à estrutura atual do projeto. Se o arquivo principal for `app.py` e ele iniciar a aplicação Flask, você poderá executar:

```bash
python app.py
```

Depois, acesse o endereço local exibido no terminal, normalmente `http://127.0.0.1:5000`.
